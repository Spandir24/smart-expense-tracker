# Smart Expense Tracker

A full-stack expense tracking application built with the MERN stack. It allows users to record, manage, search, and filter their income and expenses.

## Features

- Add income and expense transactions
- Edit existing transactions
- Delete transactions
- View total income, expenses, and balance
- Search transactions by title
- Filter transactions by type
- Store transactions in MongoDB
- Responsive user interface using Tailwind CSS

## Tech Stack

### Frontend

- React
- JavaScript
- Tailwind CSS
- Vite

### Backend

- Node.js
- Express.js
- REST API

### Database

- MongoDB
- Mongoose
